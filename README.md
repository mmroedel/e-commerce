## 🎯 Sobre o Projeto

A **MM STORE** é um projeto de e-commerce desenvolvido como parte do curso de extensão da UC **FRAMEWORK FRONT-END COM CONSUMO DE API**. O objetivo principal é demonstrar a proficiência na integração de um *front-end* puro (Vanilla) com serviços de dados externos, simulando uma loja virtual completa.

Este projeto utiliza dados de produtos fornecidos pela API pública `https://dummyjson.com/products` para preencher dinamicamente o catálogo.

## ✨ Funcionalidades em Destaque

O e-commerce **MM STORE** implementa funcionalidades obrigatórias e extras, demonstrando a capacidade de construir sistemas interativos e dinâmicos:

| Recurso | Descrição | Status |
| :--- | :--- | :--- |
| **Simulador de Pagamento** | Ao clicar no botão de compra, um **Modal** é carregado apresentando um QR Code estático para simular uma transação (PIX ou similar). | **Requisito Atendido** |
| **Carregamento Dinâmico** | Implementação de um botão "Carregar Mais Produtos" para otimizar o desempenho e a experiência do usuário ao navegar pelo catálogo. | **Requisito Atendido** |
| **Carrinho de Compras** | Funcionalidade **Extra** que permite aos usuários adicionar, remover e visualizar itens antes de finalizar a compra. | **Recurso Extra** |
| **Visualização de Dados** | Integração da biblioteca **Chart.js** para exibir gráficos e estatísticas relevantes (ex: inventário, vendas simuladas, etc.). | **Requisito Atendido** |
| **Geolocalização** | Uso da API de **Geolocation** do navegador para obter a localização do usuário, que pode ser usada para cálculo de frete ou exibição de lojas próximas. | **Requisito Atendido** |

## 🛠️ Como Executar o Projeto Localmente

Siga estes passos simples para ter uma cópia do projeto em execução na sua máquina.

### Pré-requisitos

Certifique-se de ter o **Node.js** e o **npm (ou yarn)** instalados.

### Instalação

1.  **Clone o repositório:**
    ```bash
    git clone "https://github.com/mmroedel/e-commerce.git"
    ```
2.  **Acesse o diretório do projeto:**
    ```bash
    cd MM-STORE
    ```
3.  **Instale as dependências (se houver um `package.json`):**
    ```bash
    npm install
    ```
4.  **Acesse o projeto:**
    Vá até o local do arquivo e abra o index.html
